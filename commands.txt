CHECK THE DATA

Quick health check: service state, last status line, drops, rows per venue, open episodes.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'systemctl is-active sportsarb-recorder; tail -1 SportsArb/data/record.log | cut -c1-170; echo "drops: $(grep -c dropped SportsArb/data/record.log)"; sqlite3 SportsArb/data/sportsarb.sqlite "select venue, count(*), count(distinct contract_id), max(ts) from quotes group by 1; select venue, count(*), round(sum((julianday(end_ts)-julianday(start_ts))*86400)) as seconds_down from gaps group by 1; select kind, count(*), round(max(peak_profit),2), sum(annual_pct >= 10) from opportunities group by 1;"'

Full summary from the summary script, last 24 hours.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'cd SportsArb && python3 src/tools/summary.py --hours 24'

Watch the log live. Stop with ctrl-c.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 tail -f SportsArb/data/record.log

Episodes the scanner logged, and its ten minute summaries.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'grep -E "episode|scanner:" SportsArb/data/record.log | tail -40'

Paper trading: the executor, settlement, and transfer lines from the log, then trades by outcome and open positions.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'grep -E "paper|settled|transfer" SportsArb/data/record.log | tail -30; sqlite3 -header -column SportsArb/data/sportsarb.sqlite "select status, count(*) as trades, sum(matched) as matched, round(sum(profit + hedge_pnl), 2) as net from trades group by 1; select venue, round(sum(amount), 2) as ledger from ledger group by 1; select count(*) as open_trades from trades where settled_at is null and yes_held + no_held > 0;"'

Largest episodes in the database.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'sqlite3 -header -column SportsArb/data/sportsarb.sqlite "select label, trade, round(100*peak_edge,1) as edge_c, round(peak_size) as size, round(peak_profit,2) as profit, round(seconds) as secs, substr(peak_ts,12,8) as at_utc from opportunities order by peak_profit desc limit 15"'

Copy the database home for analysis. The recorder keeps running.
    rsync -avz -e "ssh -i ~/.ssh/sportsarb-us.pem" ubuntu@54.82.110.237:SportsArb/data/sportsarb.sqlite* ~/Projects/SportsArb/data/aws/


RUN THE RECORDER

Start the recorder if it was stopped. It also starts on boot.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'sudo systemctl start sportsarb-recorder'

Stop the run.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'sudo systemctl stop sportsarb-recorder'

Deploy after committing and pushing. Restarts the recorder, which refreshes the catalog for about 80 seconds.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'cd SportsArb && git pull && python3 -m pytest -q | tail -1 && sudo systemctl restart sportsarb-recorder'

Start fresh. Deletes the database on the instance and starts a new run.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'sudo systemctl stop sportsarb-recorder && rm -f SportsArb/data/sportsarb.sqlite* && mv SportsArb/data/record.log SportsArb/data/record_old.log; sudo systemctl start sportsarb-recorder'


INSTANCE

Open a shell.
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237

Allow SSH from the laptop's current IP. Needed when the IP changes, for example when the VPN toggles.
    aws ec2 authorize-security-group-ingress --region us-east-1 --group-id sg-0a601fd37e4a97089 --protocol tcp --port 22 --cidr $(curl -s https://checkip.amazonaws.com)/32

Instance state, CPU over the last hour, disk.
    aws ec2 describe-instances --region us-east-1 --instance-ids i-0a0119ff5a49fe57a --query "Reservations[].Instances[].[State.Name,PublicIpAddress]" --output text
    aws cloudwatch get-metric-statistics --region us-east-1 --namespace AWS/EC2 --metric-name CPUUtilization --dimensions Name=InstanceId,Value=i-0a0119ff5a49fe57a --start-time $(date -u -v-1H +%Y-%m-%dT%H:%M:%SZ) --end-time $(date -u +%Y-%m-%dT%H:%M:%SZ) --period 300 --statistics Average Maximum --query "sort_by(Datapoints,&Timestamp)[].[Timestamp,Average,Maximum]" --output text
    ssh -i ~/.ssh/sportsarb-us.pem ubuntu@54.82.110.237 'df -h / | tail -1; ls -la --block-size=M SportsArb/data/sportsarb.sqlite'

Stop and start the instance itself. Stopping saves the compute cost but keeps the disk. The public IP changes on start.
    aws ec2 stop-instances --region us-east-1 --instance-ids i-0a0119ff5a49fe57a
    aws ec2 start-instances --region us-east-1 --instance-ids i-0a0119ff5a49fe57a
